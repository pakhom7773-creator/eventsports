# 📦 JavaFX приложение для сдачи

## Информационно-справочная система спортивных мероприятий

**Платформа:** JavaFX  
**Тип:** Desktop приложение с графическим интерфейсом

---

## ✅ Реализованный функционал

### 1. Графический интерфейс ✅
- Окно авторизации (Login.fxml)
- Главное окно с поиском (Main.fxml)
- Админ-панель (Admin.fxml)
- Современный дизайн JavaFX

### 2. Регистрация и авторизация ✅
- Форма регистрации с выбором роли
- Форма входа
- JWT аутентификация
- Сохранение сессии

### 3. Отображение данных в таблице ✅
- Таблица мероприятий в админ-панели
- Колонки: Название, Вид спорта, Место
- Возможность выбора строк

### 4. Добавление в БД ✅
- Создание мероприятий (для организаторов)
- Регистрация пользователей
- Все данные сохраняются через API

### 5. Поиск и вывод записей ✅
- Поиск по названию мероприятия
- Фильтр по виду спорта (выпадающий список)
- Фильтр по городу
- Фильтр по дате (от/до)
- Кнопка "Найти" для применения фильтров

### 6. Сортировка записей ✅
- Сортировка по дате начала (автоматически)
- Можно добавить сортировку по другим полям

### 7. Разделение ролей ✅
- **user** - обычный пользователь
  - Просмотр мероприятий
  - Поиск и фильтрация
- **organizer** - организатор
  - Все функции user +
  - Создание мероприятий
- **admin** - администратор
  - Все функции organizer +
  - Доступ к админ-панели
  - Управление мероприятиями
  - Удаление мероприятий

## 🚀 Запуск приложения

### Требования:
- Java 17+
- Maven 3.6+
- Backend должен быть запущен (см. ниже)

### Шаг 1: Запустить Backend

```bash
cd ../backend_java
mvn spring-boot:run
```

Backend будет на: http://localhost:8000

### Шаг 2: Запустить JavaFX приложение

```bash
cd javafx_app
mvn clean javafx:run
```

Приложение откроется автоматически.

```
│   ├── Main.java                    # Точка входа приложения

│   │   ├── AuthController.java     # Авторизация и регистрация
│   │   ├── MainController.java     # Главное окно с поиском
│   │   └── AdminController.java   # Админ-панель
│   ├── models/                     # Модели данных
│   │   ├── User.java               # Пользователь

│   │   └── ...
│   ├── api/                        # API клиент
│   │   └── ApiClient.java         # HTTP запросы к backend
│   └── utils/                      # Утилиты
│       └── SceneManager.java      # Управление окнами
└── src/main/resources/
    └── fxml/                       # FXML файлы (UI)
        ├── Login.fxml             # Окно авторизации
        ├── Main.fxml              # Главное окно
        └── Admin.fxml             # Админ-панель
```

## 🎨 Интерфейс

### Окно авторизации
- Поле Email
- Поле Пароль
- Кнопка "Войти"
- Переключение на регистрацию
- Выбор роли при регистрации

### Главное окно
- Верхняя панель с информацией о пользователе
- Фильтры поиска:
  - Поиск по названию
  - Вид спорта (ComboBox)
  - Город
  - Дата от/до (DatePicker)
- Список мероприятий в виде карточек
- Кнопка "Создать мероприятие" (для организаторов)
- Кнопка "Админ-панель" (для админов)

### Админ-панель
- Статистика (4 карточки):
  - Пользователей
  - Мероприятий
  - Организаторов
  - Отзывов
- Таблица мероприятий:
  - Название
  - Вид спорта
  - Место
- Кнопка "Удалить" для выбранного мероприятия
- Кнопка "Назад"
